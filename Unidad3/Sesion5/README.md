# Unit 3 – Session 5: Sarek Pipeline for Variant Analysis

## Introduction

This session explores a complete bioinformatics pipeline for genetic variant detection, based on the Sarek tool from the nf-core community. Sarek is a reproducible workflow that automates the main steps of next-generation sequencing (NGS) data analysis, from raw read preprocessing to variant calling and annotation. This pipeline is designed to work with whole-genome sequencing (WGS) data or targeted panels, and leverages standardized tools combined in a modular and scalable workflow, making it ideal for reproducible research projects. :contentReference[oaicite:0]{index=0}

## Session Content

### 🧠 What is Sarek?

[Sarek](https://github.com/maluflorezg/Tareas_BioinfRepro2025_MLFG/tree/main/Unidad3/Sesion5/pipeline_sarek) is a variant analysis pipeline developed by the nf-core community, designed to perform a complete DNA sequencing data analysis reproducibly and portably. It can handle whole genome data or targeted panels, and is built on the Nextflow workflow manager, allowing the same analysis to be run in different environments (local, HPC, or containers). :contentReference[oaicite:5]{index=5}

---

### 🧩 Main Pipeline Stages

This pipeline may include the following steps (depending on the configuration and data):

- **Read Quality Control** (e.g., *FastQC*, *fastp*)
- **Read Alignment to the Reference Genome** (*BWA-MEM*, *BWA-MEM2*)
- **Alignment File Processing** (marking duplicates, base recalibration)
- **Variant Calling** (tools such as *GATK*, *FreeBayes*, etc.)
- **Variant Filtering and Normalization**
- **Variant Functional Annotation** (*SnpEff*, *VEP*)
- **Statistics Summary and Reporting** (*MultiQC*) :contentReference[oaicite:6]{index=6}
