# Unit 4 – Session 3: Preprocessing RNA-seq Reads

## Introduction

In this session, we will perform **preprocessing of reads**, including filtering and truncation, with the goal of improving the quality of the data used in gene expression analysis.

--

## Objectives

- Apply read filtering and truncation methods.

- Understand the impact of preprocessing on data quality.

- Generate reads ready for further analysis.

## Content

- Removing low-quality sequences.
