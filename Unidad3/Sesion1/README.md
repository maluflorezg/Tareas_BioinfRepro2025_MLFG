# Unit 3 – Session 1

## Introduction

This session introduces the basic concepts related to DNA sequencing data analysis and the study of genomic variants. It reviews the most common file types and the general stages of a variant analysis workflow.

--

## Objectives

- Understand the general workflow of genomic variant analysis.

- Recognize the main data formats used in NGS.

- Prepare the work environment for subsequent analysis.

--

## Content

- Review of input data for genomic analysis.

- Initial organization of files and folders.

- Introduction to the stages of variant analysis.
