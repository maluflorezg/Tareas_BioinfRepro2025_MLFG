# Unit 3 – Genomic Variant Analysis and Reproducible Pipelines

## Introduction

Unit 3 focuses on **genomic variant analysis using next-generation sequencing (NGS) data**, integrating theoretical and practical concepts through the use of reproducible bioinformatics tools. This unit explores different stages of data processing, from handling sequencing files to implementing automated pipelines for variant calling and annotation.

The main emphasis is on understanding how bioinformatics workflows are structured, how multiple tools are integrated into a pipeline, and how to document these analyses clearly and reproducibly.

--

## Unit Objectives

By the end of this unit, students are expected to be able to:

- Understand the main stages of genomic variant analysis using NGS data.

- Manage files and formats used in genomic analysis pipelines.

- Apply bioinformatics tools for the processing and analysis of sequencing data.

- Understand the logic of automated pipelines and their importance for reproducibility.

- Document and organize complex analyses using Markdown and version control.

---

## Content Description

This unit is divided into several sessions, each focused on a particular aspect of genomic variant analysis:
- Introductory sessions: Introduction to sequencing data handling and the basic stages of analysis.

- Intermediate sessions: Processing, quality control, and analysis of genomic data.

- Advanced sessions: Implementation and understanding of complete bioinformatics pipelines, such as Sarek, for reproducible variant analysis.

    - Session 1: NGS reading quality control

    - Session 2: cBioPortal for analyzing genomic cancer data

    - Session 3: Sequence Analysis

    - Session 4: Variant Analysis with CLC Genomics Workbench

    - Session 5: Germinal and Somatic Analysis with nf-core/sarek
