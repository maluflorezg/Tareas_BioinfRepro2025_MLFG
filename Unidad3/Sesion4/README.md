# Unit 4 – Session 4: Quantification and Preparation of Expression Data

## Introduction

This session covers the **quantification of gene expression** and the preparation of data for statistical analysis. Processed readings are transformed into count matrices that represent gene expression levels.

--

## Objectives

- Understand the process of gene expression quantification.
- Generate count matrices from RNA-seq data.
- Prepare data for differential expression analysis.

--

## Content

- Quantification of readings.
- Generation of expression matrices.
- Organization of data for statistical analysis.
