# Unit 1 – Introduction to Reproducible Bioinformatics

## Introduction

This first unit covers the fundamental concepts of reproducible bioinformatics and its basic application using tools such as Git/GitHub and R. The objective is to become familiar with the use of version control to organize tasks and documents, as well as to apply basic operations in R with a bioinformatics approach. This unit lays the foundation for the following units of the course, promoting good practices in organization, documentation, and reproducibility of analysis.

--

## Unit Objectives

- Understand how to structure and version projects with Git and GitHub.

- Apply basic Git commands to manage changes in the repository.

- Perform basic operations in R with a focus on data analysis.

- Document tasks and exercises clearly using Markdown and supplementary files (PDF, TXT).

- Become familiar with organizing tasks by sessions and using folders to separate inputs, code, and results.

---

## Content Description

This unit is divided into three sessions that include exercises, assignments, and documentation, organized as follows:

### 🧪 Session 1 – Introduction / First Exercises

---

### 📊 Session 3 – Introduction to R with a Bioinformatics Focus

This session includes:
- Development of Task 03 in Markdown format with R exercises.

The exercises in this session are designed to reinforce R programming concepts and their application to simple tasks related to bioinformatics.

---

## Folder Organization

Within this unit, each session is organized in its own folder to facilitate navigation and reproducibility of the content. In general, sessions may contain:

- `data/` → inputs and text files used.

- `code/` → code or task development.

- `docs/` → external documents, such as PDFs of submissions.

- `results/` → key results, if applicable.

- `figures/` → generated figures and graphs.

- Notes or additional files depending on the session.

---

> **Note:** This structure keeps each task organized and facilitates reading and assessment without having to access disorganized files.
