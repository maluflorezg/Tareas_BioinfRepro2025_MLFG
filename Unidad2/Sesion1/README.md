# Unit 2 – Session 1: Genetic Data

## Introduction

In this first session of Unit 2, we focus on understanding the **fundamentals of genetic data** used in population genetics and bioinformatics. Unlike other areas of data analysis, population genetics requires standardized formats (such as VCF or PLINK) that contain information about genetic variants, individuals, and populations. This session lays the groundwork for subsequent analyses by familiarizing us with these formats and the tools that process them. :contentReference[oaicite:0]{index=0}

---

## Objectives

By the end of this session, you should be able to:

1. Know the main **genetic data formats** (e.g., VCF and PLINK). :contentReference[oaicite:1]{index=1}
2. Understand what information each format stores and what it is used for. :contentReference[oaicite:2]{index=2}
3. Identify **packages and tools** in R or other environments that allow reading and manipulating this data for further analysis. :contentReference[oaicite:3]{index=3}
4. Organize the data and resources needed for the exercises in this unit in a reproducible and clear way.

---

## Content

### 📌 Genetic Data Formats

- **VCF (Variant Call Format)**: a tabular text format that describes genetic variants (SNPs, INDELs) in one or more samples.

- **PLINK**: a set of formats (e.g., `.bed`, `.bim`, `.fam`) widely used for genetic data analysis in human and animal populations.
Files of this type contain information about individuals, variants, genotypes, and metadata necessary for subsequent population analyses. :contentReference[oaicite:4]{index=4}

### 🔍 Tools for Reading and Manipulating Data

During this session, we will review and use tools and packages that allow you to:

- Load VCF and Plink data into R or other environments.

- Explore genetic data structures (allelic frequencies, number of loci, etc.).

- Prepare data for subsequent exploratory analysis.
